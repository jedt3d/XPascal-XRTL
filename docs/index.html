Bootstrap Status

Windows x86_64, macOS Apple Silicon aarch64, and Linux x86_64 / Ubuntu 26.04 have passed bootstrap validation. macOS Intel x86_64 is intentionally unsupported. Supported FPC snapshot SHA256 values are pinned in the toolchain lock.
