เอกสารนักพัฒนา XPascal

เอกสารภาษาไทยสำหรับช่วง bootstrap ของ XPascal/XRTL โดยยึดเอกสารภาษาอังกฤษเป็นต้นฉบับก่อน แล้วแปล/ปรับภาษาไทยให้อ่านเป็นธรรมชาติ ฐาน bootstrap ถูก merge แล้วใน PR #8

เริ่มอ่านตรงนี้

  • Bootstrap Toolchain
  • บันทึกกัปตัน
  • ข้อเสนอแพลตฟอร์มต้นฉบับ

ขอบเขตตอนนี้

ช่วง bootstrap พิสูจน์ว่าโปรเจกต์สามารถติดตั้งและตรวจ FreePascal 3.3.1, build CLI ตัวแรกชื่อ xpc, และรัน smoke test บน Windows x86_64, macOS Apple Silicon aarch64, และ Linux x86_64 / Ubuntu 26.04 ได้แล้ว

กฎการทำงาน

งานที่ไม่ใช่งานเล็กน้อยต้องเริ่มจาก GitHub issue เสมอ ทำบน branch และ PR ที่ trace ได้ ทดสอบ platform ที่เกี่ยวข้อง อัปเดตบันทึกกัปตันและ issue map แล้วเทียบผลลัพธ์กับ acceptance criteria ของ issue ก่อนปิดงาน
