เริ่มอ่านตรงนี้

  • Bootstrap Toolchain
  • บันทึกกัปตัน
  • ข้อเสนอแพลตฟอร์มต้นฉบับ

ขอบเขตตอนนี้

ช่วง bootstrap พิสูจน์ว่าโปรเจกต์สามารถติดตั้งและตรวจ FreePascal 3.3.1, build CLI ตัวแรกชื่อ xpc, และรัน smoke test บน platform หลักได้
