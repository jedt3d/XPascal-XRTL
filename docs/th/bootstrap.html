Bootstrap Toolchain

งานชุดแรกของ XPascal/XRTL คือสร้างฐานที่ build ได้ ตรวจสอบได้ และใช้ FreePascal 3.3.1 แบบชัดเจน

Platform ที่รองรับ

  • Windows x86_64: ทดสอบผ่านแล้ว
  • macOS Apple Silicon aarch64: ทดสอบผ่านแล้ว
  • Linux x86_64 / Ubuntu 26.04: ทดสอบผ่านแล้ว

macOS Intel x86_64 ไม่อยู่ใน scope และไม่รองรับโดยตั้งใจ

Windows

./tools/install-fpc.ps1
./tools/check-toolchain.ps1
./tools/build-xpc.ps1
./tools/run-xpc.ps1 version
./tools/run-xpc.ps1 doctor
./build/hello_xpc.exe

macOS Apple Silicon และ Linux

bash ./tools/install-fpc.sh
bash ./tools/check-toolchain.sh
bash ./tools/build-xpc.sh
bash ./tools/run-xpc.sh version
bash ./tools/run-xpc.sh doctor
./build/hello_xpc

หมายเหตุแต่ละ Platform

  • Windows ใช้ compiler จาก snapshot ผ่าน ppcrossx64.exe และควรรันผ่าน tools/run-xpc.ps1
  • macOS Apple Silicon ใช้ compiler จริงชื่อ ppca64 พร้อม FPC unit path และ macOS SDK link flags
  • Linux x86_64 เลือก ppcx64 ก่อน fpc และ pin SHA256 ของ snapshot แล้ว

Baseline หลัง Merge

PR #8 merge ฐาน bootstrap เข้า main แล้ว หลังทดสอบสดบน Windows x86_64, macOS Apple Silicon aarch64, และ Ubuntu 26.04 x86_64 ส่วน issue #9 ยังติดตามการ pin SHA256 ของ snapshot Windows/macOS ก่อน release packaging

แต่ละ script ทำอะไร

  • install-fpc ดาวน์โหลดและแตก FPC 3.3.1 snapshot สำหรับ platform ปัจจุบัน
  • check-toolchain ตรวจว่า compiler รายงาน version เป็น 3.3.1
  • build-xpc build CLI bootstrap และ smoke executable
  • run-xpc รัน CLI พร้อม metadata ของ compiler ที่ตรวจแล้ว
