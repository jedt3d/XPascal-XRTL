XPascal / XRTL Roadmap Gantt

This roadmap shows the current phase plan, issue links, and dependency gates. It is a planning aid, not a release promise. Update it whenever a phase changes, an issue closes, or a new platform gate appears.

Current support focus: Windows x86_64, macOS Apple Silicon aarch64, and Ubuntu 26.04 x86_64. macOS Intel x86_64 is out of scope by decision.

Toolchain invariant: FreePascal must report 3.3.1 through the bootstrap scripts and CLI doctor path.

Dependency Notes

  • Foundation issues #1 through #7 are complete through PR #8.
  • Post-merge workflow #11, FPC checksum finalization #9, and agent harness refresh #14 are complete.
  • Roadmap issue #16 and PRD/ADR cadence issue #18 are complete.
  • Windows, macOS Apple Silicon, and Ubuntu bootstrap validation evidence exists from the bootstrap and checksum closeout passes. The next CLI v0 PR should refresh affected validation logs instead of reopening a standalone platform gate.
  • Runtime implementation should wait until the first runtime surface area is defined in an issue and, where needed, an architecture decision record.
