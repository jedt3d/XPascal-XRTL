XPascal / XRTL Roadmap Gantt

This roadmap shows the current phase plan, issue links, and dependency gates. It is a planning aid, not a release promise. Update it whenever a phase changes, an issue closes, or a new platform gate appears.

Current support focus: Windows x86_64, macOS Apple Silicon aarch64, and Ubuntu 26.04 x86_64. macOS Intel x86_64 is out of scope by decision.

Toolchain invariant: FreePascal must report 3.3.1 through the bootstrap scripts and CLI doctor path.
