XPascal / XRTL Roadmap Gantt

This roadmap shows the current phase plan, issue links, and dependency gates. It is a planning aid, not a release promise. Update it whenever a phase changes, an issue closes, or a new platform gate appears.

Current support focus: Windows x86_64, macOS Apple Silicon aarch64, and Ubuntu 26.04 x86_64. macOS Intel x86_64 is out of scope by decision.

Toolchain invariant: FreePascal must report 3.3.1 through the bootstrap scripts and CLI doctor path.

Dependency Notes

  • Foundation issues #1 through #7 are complete through PR #8.
  • Post-merge workflow #11, FPC checksum finalization #9, and agent harness refresh #14 are complete.
  • Roadmap issue #16 and PRD/ADR cadence issue #18 are complete.
  • Windows, macOS Apple Silicon, and Ubuntu bootstrap validation evidence exists from the bootstrap and checksum closeout passes. The next CLI v0 PR should refresh affected validation logs instead of reopening a standalone platform gate.
  • Issue #26 is complete through PR #30. It defines the XRTL planning gate: shared architecture, per-library docs, no-duplication rules, and test strategy before runtime implementation grows.
  • Issue #32 is complete through PR #33. It defines flat unit name xrtl_core, Core v0 primitives, and release-note-first FPC research evidence.
  • Issue #34 is complete through PR #35. It added XRTL.Core v0, Core tests, build-script integration, and three-platform validation.
  • Issue #27 is complete through PR #36. Epic #24 is complete through PR #37. Issue #28 records source-backed Database/Web recommendations without adopting third-party code.
  • Issue #39 refines the next slice: XRTL.Database starts local SQLite-only through SQLDB, network databases are deferred, XRTL.HTTP starts with FCL-Web vs fphttpserver research, and XRTL.Web starts with provider-neutral middleware design inspired by Rack/Horse.
  • Issue #40 implements XRTL.Database v0 as local SQLite over SQLDB only, with network databases deferred to later service-validation issues.
  • Issue #45 completes the macOS Apple Silicon rerun for Database SQLite v0 on merged main; the SQLite tests passed with FPC 3.3.1.
  • Issue #47 defines the local-only Database feature-stack sequence. Issue #48 implements public transactions and parameter binding as the first slice. Issue #50 implements detached raw row/field/value mapping as the second slice. Issue #52 implements app dataset iteration over detached rows as the third slice. Issue #54 implements the SQLite-only provider facade as the fourth slice. Issue #56 implements apply-only migration primitives as the fifth slice. Issue #58 implements SELECT query builder primitives as the sixth slice. Issue #60 completes the epic with ORM mapping primitives. PostgreSQL, MySQL/MariaDB, and Firebird stay out of scope.
  • Issue #62 defines the ORM V1 implementation strategy before more Database implementation proceeds. It keeps execution SQLite-only, starts caching with schema/generated-SQL/session identity-map caches, separates attachment upload/storage from ORM metadata, and uses SQLModel/SQLAlchemy as clean-room benchmarks.
  • Issue #64 implements that first ORM V1 slice: CRUD mapper, repository/session/unit-of-work, schema/generated-SQL/session identity-map caching, and attachment metadata without file bytes.
