Current Scope

The bootstrap phase proves that the project can install and verify FreePascal 3.3.1, build the first xpc CLI, and run smoke checks on Windows x86_64, macOS Apple Silicon aarch64, and Linux x86_64 / Ubuntu 26.04.

Working Rule

Start each non-trivial change from a GitHub issue, work on a traceable branch and PR, validate the affected platforms, update the Captain's Log and issue map, then compare the result back against the issue acceptance criteria before closing.
