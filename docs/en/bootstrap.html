Bootstrap Toolchain

The first XPascal/XRTL slice focuses on a reproducible CLI-first foundation using FreePascal 3.3.1.

Supported Platforms

  • Windows x86_64: validated
  • macOS Apple Silicon aarch64: validated
  • Linux x86_64 / Ubuntu 26.04: validated

macOS Intel x86_64 is intentionally not supported.

Windows

./tools/install-fpc.ps1
./tools/check-toolchain.ps1
./tools/run-xpc.ps1 build
./tools/run-xpc.ps1 version
./tools/run-xpc.ps1 doctor
./build/hello_xpc.exe

macOS Apple Silicon And Linux

bash ./tools/install-fpc.sh
bash ./tools/check-toolchain.sh
bash ./tools/run-xpc.sh build
bash ./tools/run-xpc.sh version
bash ./tools/run-xpc.sh doctor
./build/hello_xpc

Platform Notes

  • Windows uses the FPC snapshot compiler through ppcrossx64.exe and the safe launcher tools/run-xpc.ps1.
  • macOS Apple Silicon uses the real compiler ppca64, explicit FPC unit paths, and macOS SDK link flags.
  • Linux x86_64 prefers ppcx64 before fpc and has a pinned snapshot SHA256.

Merged Bootstrap Baseline

PR #8 merged the bootstrap baseline into main after fresh validation on Windows x86_64, macOS Apple Silicon aarch64, and Ubuntu 26.04 x86_64. Supported FPC snapshot SHA256 values are pinned in toolchains/fpc-3.3.1.lock and verified before extraction.

What The Scripts Do

  • install-fpc downloads and extracts the locked FPC 3.3.1 snapshot for the current platform.
  • check-toolchain verifies that the selected compiler reports 3.3.1.
  • run-xpc build builds the bootstrap CLI and smoke executable through the public CLI v0 launcher path.
  • run-xpc launches the CLI with verified compiler metadata.
