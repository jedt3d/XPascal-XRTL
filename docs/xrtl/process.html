XRTL.Process

Status: planned. No implementation exists yet.

Purpose

Process owns command execution, executable discovery, environment access, OS/CPU detection, and exit-code contracts.

Responsibilities

  • Executable lookup and path probing.
  • Process execution result shape: command, exit code, stdout/stderr capture, elapsed time.
  • OS and CPU detection shared by CLI, build, and tests.
  • Safe shell-avoidance policy for command execution.

Non-Responsibilities

  • No filesystem abstraction beyond executable lookup; IO owns paths and files.
  • No build orchestration policy by itself; XCLI or build tools consume Process.
  • No direct dependency on Database, HTTP, or Web.

Dependencies

Process may depend on Core, Diagnostics, IO, Text, and Time.

Refactor Check

The first macOS bootstrap found that naive Pascal process execution can crash in some paths. Process must be introduced with focused platform tests before it replaces shell launcher behavior.

First Tests

  • OS/CPU detection tests on Windows, macOS Apple Silicon, and Ubuntu.
  • Executable lookup success and failure tests.
  • Process execution smoke using a harmless command on each platform.
