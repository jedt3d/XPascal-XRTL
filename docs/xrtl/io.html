XRTL.IO

Status: planned. No implementation exists yet.

Purpose

IO owns path, file, stream, directory, and temporary workspace behavior so build, project creation, tests, and web/static file features do not each invent filesystem rules.

Responsibilities

  • Path normalization and joining.
  • Safe file read/write primitives.
  • Directory creation and cleanup policy.
  • Temporary directory helpers for tests and generated project smoke checks.

Non-Responsibilities

  • No process execution; Process owns command running.
  • No web static-file server behavior; Web may consume IO.
  • No database file format behavior.

Dependencies

IO may depend on Core, Diagnostics, Text, and Time. It must not depend on Database, HTTP, or Web.

Refactor Check

Generated project creation, toolchain lookup, HTTP static files, and tests should use the same path and temporary directory policy. Any duplicate path helper should be moved here or explicitly justified.

First Tests

  • Path join tests for Windows and POSIX separators.
  • Temporary directory lifecycle tests.
  • Read/write failure tests for missing files and existing directories.
