XRTL.Time

Status: planned. No implementation exists yet.

Purpose

Time owns clocks, durations, timeouts, and timestamp contracts so tests and adapters do not invent incompatible time handling.

Responsibilities

  • Clock abstraction for real and test clocks.
  • Durations and timeout values.
  • UTC timestamp representation policy.
  • Monotonic elapsed-time measurement for diagnostics and process execution.

Non-Responsibilities

  • No scheduling engine.
  • No timezone database unless a future issue proves it is needed.
  • No logging of timings; Diagnostics owns emitted events.

Dependencies

Time may depend on Core after Core exists. It should not depend on Config, IO, Process, Database, HTTP, or Web.

Refactor Check

Database timeouts, HTTP request deadlines, Web middleware timings, and Process execution timeouts should all use Time contracts instead of local integer timeout conventions.

First Tests

  • Duration conversion tests.
  • Fake clock tests for deterministic elapsed time.
  • Platform smoke for monotonic clock availability.
