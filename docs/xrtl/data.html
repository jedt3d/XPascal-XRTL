XRTL.Data

Status: planned. No implementation exists yet.

Purpose

Data owns database-neutral data contracts: rows, fields, parameters, records, cursor-like iteration, and data errors. It prevents Database adapters from leaking driver-specific types into user code.

Responsibilities

  • Data value and field metadata contracts.
  • Parameter binding shape independent of SQLDB, Zeos, mORMot, or any future backend.
  • Result iteration policy and error mapping.
  • Small serialization boundary decisions when they are not full JSON or ORM features.

Non-Responsibilities

  • No database connection or SQL execution.
  • No ORM, migration system, or schema management in the first plan.
  • No HTTP or Web routing concepts.

Dependencies

Data may depend on Core, Collections, Text, Time, and Diagnostics. It must not depend on Database.

Refactor Check

If Database, Web, or future CLI commands need tabular data, they should consume Data contracts. Duplicated row/field abstractions are a red flag and should be moved here before implementation expands.

First Tests

  • Field type mapping tests.
  • Parameter binding shape tests without a real database.
  • Result iteration and error propagation contract tests.
